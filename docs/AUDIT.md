# Аудит mcp-servers-for-revit

Дата: 2026-10-28. Ветка исправлений: `fix/stability-audit`.
Ход работ по этапам: [CHANGELOG-stability.md](CHANGELOG-stability.md).

## Архитектура

```
LLM-клиент ──stdio──► MCP-сервер (Node, server/) ──TCP JSON-RPC──► плагин Revit (plugin/)
                                                                     │ ExternalEvent
                                                                     ▼
                                                     обработчики команд (commandset/)
```

## Найденные проблемы

Статус: ✅ исправлено, ⏸ отложено (с причиной).

### Критично: стабильность и безопасность

| # | Проблема | Где | Статус |
|---|----------|-----|--------|
| 1 | Порт 8080 жёстко прошит в плагине и сервере; конфликтует с другими сервисами (например, эмбеддингами revit-kb). Ошибка `Start()` проглатывалась, пользователь видел «Open Server» | `SocketService.cs`, `ConnectionManager.ts` | ✅ этап 0 |
| 2 | Плагин слушал `IPAddress.Any` без авторизации, а `send_code_to_revit` выполняет любой C# — удалённое выполнение кода из локальной сети | `SocketService.cs` | ✅ этап 0 |
| 3 | Нет фрейминга TCP: один `Read(8192)` считался целым сообщением, запросы > 8 КБ рвались; клиент делал `JSON.parse` на каждый пакет (O(n²)) | `SocketService.cs`, `SocketClient.ts` | ✅ этап 1 |
| 4 | Гонка в `WaitForCompletion`: SDK вызывает `Raise()`, затем обработчик делает `Reset()` — быстрый результат терялся, получался ложный таймаут (подтверждено декомпиляцией RevitMCPSDK) | все ~23 обработчика | ✅ этап 0 |
| 5 | `TaskDialog.Show` при ошибке в 13 обработчиках: модальное окно блокирует Revit, клиент ждёт таймаута, ошибка теряется | `commandset/Services` | ✅ этап 0 |
| 6 | Общее состояние обработчиков: после таймаута событие остаётся в очереди, а следующий запрос перезаписывает параметры; результат `Raise()` не проверялся | `ExternalEventCommandBase` (SDK) | ✅ этап 1 |
| 7 | Нет обработки предупреждений Revit: модальный диалог предупреждения подвешивает вызов | плагин | ✅ этап 1 |

## План

0. Быстрые исправления: порт 8964 только на loopback, гонка ожидания, модальные окна, `isError`, мёртвый код, логгер.
1. Транспорт: NDJSON-фрейминг, постоянное соединение, сопоставление по id, согласованные таймауты, сериализация команд, перехват предупреждений Revit.
2. Команды Revit: параметры через `BuiltInParameter`, оптимизация коллекторов, единицы мм, доработка `send_code`.
3. MCP-сервер: обновление SDK, явный реестр инструментов, путь к БД, версия.
4. Тесты и CI.
